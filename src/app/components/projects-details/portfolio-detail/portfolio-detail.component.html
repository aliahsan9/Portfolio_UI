THE PURPOSE

Make the work understandable, not just visible.

A GitHub repository can demonstrate implementation, but it doesn't always explain why a project exists, which problem it addresses, or what engineering decisions shaped it. A list of skills has the same limitation: it tells visitors what a developer knows, not how that knowledge is applied.

I built this portfolio to bridge that gap. It brings project explanations, technology choices, source code, live demos, and contact options into one place.

The portfolio is also a frontend engineering project in its own right. Its structure, responsiveness, content hierarchy, visual consistency, and deployment all contribute to the experience—not just the appearance of the homepage.
