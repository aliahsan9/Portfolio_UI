UAFManagement System

Academic operations with rules the database can enforce.

UAF Management System is an independent academic project for university workflows: academic structure, admissions, student records, course offerings, and timetables. It is a final-year system, not an official University of Agriculture Faisalabad product.

The current repository is the .NET backend: Clean Architecture, ASP.NET Core, Entity Framework Core, SQL Server, and JWT authentication. Fees, a learning portal, and a full examination module are still ahead.

01 / The problem

A university cannot run on disconnected records.

Admissions, programs, sessions, and student status only stay consistent when the same rules apply to every request. A form or spreadsheet cannot lock the last seat or remember who accepted an application.

The objective. Build a backend where academic structure, admissions, and student records share one model, and where contested updates are decided by the database.

02 / The solution

One API for the academic year.

The system exposes versioned HTTP endpoints for the work already modeled: structure, sessions, courses, offerings, enrollment, timetable, students, and admissions.

Staff operations require the matching role. Applicant operations use the authenticated account as the owner. Broader modules such as fees, identity cards, a learning portal, and examinations remain on the roadmap.

04 / System design

Clear boundaries. Explicit responsibilities.

UAF follows the same layered shape as the other .NET systems in this portfolio: domain rules stay independent of EF Core and HTTP.

Infrastructure implements application contracts. The API project is the entry point for authentication, policies, and endpoint mapping.

05 / Security & reliability

University data needs more than a login route.

The identity foundation covers registration, login, and role checks. Email verification, refresh-token rotation, password reset, and multi-factor authentication are still future work, so this is not a production identity system yet.
