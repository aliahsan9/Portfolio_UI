Enterprise Education Platform

School Management System

A complete full-stack School Management System developed using Angular, .NET Web API, Entity Framework Core, and MS SQL Server. The platform helps schools manage students, teachers, attendance, classes, fee records, exams, notices, and administration through a modern dashboard with secure authentication and scalable architecture.

Angular .NET Web API Entity Framework Core MS SQL Server Bootstrap SCSS JWT Authentication REST APIs

Student Management

Manage student registrations, academic records, class assignments, attendance tracking, fee management, and performance reports from one centralized dashboard.

Teacher & Staff Portal

Dedicated modules for teachers and staff to manage schedules, attendance, subjects, exam grading, notices, and classroom activities efficiently.

Reports & Analytics

Generate detailed academic reports, fee summaries, attendance analytics, and administrative insights with dynamic dashboards and charts.

Architecture & Development

The backend is built using ASP.NET Core Web API with Entity Framework Core Code First approach for scalable database design and clean architecture implementation.

Angular frontend delivers responsive dashboards and modular components with Bootstrap and SCSS for a modern UI experience.

Backend: ASP.NET Core Web API
Frontend: Angular Standalone Architecture
Database: MS SQL Server
ORM: Entity Framework Core (Code First)
Authentication: JWT Authentication & Role Based Access
UI Design: Bootstrap 5 + SCSS
